# Fonts

These open-licensed fonts are bundled so clips look the same on every
computer. Each font's license file sits next to it.

| Font | Used for | License |
|---|---|---|
| Atkinson Hyperlegible (Braille Institute) | Captions and advice. It was designed for readers with low vision. | SIL Open Font License 1.1 |
| Anton | The stamp and headlines | SIL Open Font License 1.1 |
| Special Elite | Typewriter labels | Apache License 2.0 |

All three were taken from the [Google Fonts repository](https://github.com/google/fonts).
